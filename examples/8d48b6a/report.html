### 200. Successful — Created
Стр. 4, строка 131 (Часть B. REST API → Статусы → 200. Successful — Created)
{"result":"ERROR","message":"Проверьте сумму"}
Стр. 4, строка 136 (Часть B. REST API → Статусы → 400. Unsuccessful — Bad request)

Проблема: В секции `200.
