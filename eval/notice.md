# Банковские выписки для юридических лиц

## Функциональные требования
* ВС-1. Банк хранит выписку 90 дней с момента выпуска.
* ВС-2. Клиент запрашивает выгрузку только за закрытые периоды.
* ВС-3. За неделю по одной карте отправляется не более одного SMS.
* ВС-4. При смене лимита очередное достижение вызывает SMS независимо от предыдущей настройки.
* ВС-5. Выгрузку подписывают два разных сотрудника.
* ВС-6. При отзыве доступа ссылка прекращает работать немедленно.
* ВС-7. Банк выдаёт файл только в формате CSV.
* ВС-8. Каждому запросу выгрузки присваивается уникальный номер.
* ВС-9. Оператор получает результат быстро.

## Критерии приёмки
| Условия | Действие | Результат |
| --- | --- | --- |
| Выписка выпущена 60 дней назад | Скачать выписку | Удалена по истечении срока хранения в 30 дней |
| Текущий период открыт | Запросить текущую выписку | Выгрузка готова |
| Один сотрудник подписал дважды | Скачать | Подписи приняты, выгрузка готова |
| Доступ отозван вчера | Открыть сохранённую ссылку | Показана выписка |
| Клиент выбирает формат PDF | Подтвердить | Получен PDF |
| Созданы два независимых запроса | Сравнить номера | Оба имеют номер 100 |
